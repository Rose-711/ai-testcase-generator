# 🧪 AI Test Case Generator

> AI 驱动的智能测试用例生成器 — 输入模块信息，自动输出标准化测试用例

---

## 📖 项目简介

传统测试用例设计耗时且容易遗漏边界场景。本项目基于 AI 能力，通过自然语言交互，智能生成覆盖功能、边界、异常、权限、场景等全类型的测试用例，并标注每条用例的**设计方法**（等价类、边界值、场景法、正交实验法、错误推测法），帮助测试工程师高效、系统地完成测试设计。

---

## ✨ 核心功能

| 功能 | 说明 |
|:----|:-----|
| 🎯 **多类型覆盖** | 功能测试 / 接口测试 / UI 测试 / 性能测试 |
| 🧩 **多方法融合** | 等价类划分、边界值分析、场景法、正交实验法、错误推测法 |
| 📊 **标准化输出** | 统一用例表格格式，含编号/模块/步骤/预期结果/优先级/设计方法 |
| 🚦 **智能优先级** | 按 P0/P1/P2/P3 自动划分用例优先级 |
| ⚠️ **风险分析** | 自动识别潜在质量风险和改进建议 |
| ✅ **评审 CheckList** | 内置用例质量评审清单，确保覆盖完整性 |

## 🚀 快速开始

### 环境要求

- Claude Code CLI（或其他兼容 AI 工具）

### 使用方式

在项目目录下输入：

```bash
/ai-testcase
```

然后按照 AI 的引导，依次回答以下问题：

```
1. 模块名称是什么？
2. 模块类型（功能/接口/UI/性能）？
3. 核心功能描述和业务流程？
4. 有哪些输入字段和业务规则？
5. 涉及哪些角色和权限？
```

AI 会自动生成一份完整的测试用例文档。

## 📋 输出示例

### 输入

```
模块名称：用户登录
模块类型：功能测试
功能描述：用户输入用户名和密码登录，支持手机号/邮箱两种方式
输入字段：
  - 用户名：6-20位，手机号或邮箱格式
  - 密码：8-16位，含字母和数字
业务规则：连续输错5次锁定30分钟
```

### 输出

| 编号 | 测试点 | 用例标题 | 步骤 | 预期结果 | 优先级 | 类型 | 设计方法 |
|:----|:-------|:--------|:----|:--------|:------|:----|:--------|
| TC_001 | 登录 | 正确手机号+密码登录成功 | 输入正确信息→点登录 | 跳转首页 | P0 | 功能 | 场景法 |
| TC_002 | 登录 | 正确邮箱+密码登录成功 | 输入正确信息→点登录 | 跳转首页 | P0 | 功能 | 场景法 |
| TC_003 | 用户名 | 用户名为5位（少于下限） | 输入5位字符 | 提示"至少6位" | P1 | 边界 | 边界值 |
| ... | ... | ... | ... | ... | ... | ... | ... |

**完整输出包含：** 测试策略概览 + 用例明细（15-40条）+ 测试数据设计 + 风险分析 + 评审CheckList

## 🛠 设计方法论

本工具基于以下 ISTQB 测试设计技术：

| 方法 | 适用场景 |
|:----|:---------|
| **等价类划分** | 输入数据有有效/无效范围时 |
| **边界值分析** | 输入数据有明确边界时 |
| **场景法** | 核心业务流程、Happy Path + 备选流程 |
| **正交实验法** | 多参数组合场景，用最少用例覆盖最大组合 |
| **错误推测法** | 凭经验推测可能出错的场景 |
